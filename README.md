## 🎣 Czym jest NNF Map?

**NNF Map** to aplikacja dla graczy **Russian Fishing 4**, która pozwala korzystać
z interaktywnych map łowisk oraz danych społeczności **NoNameFish**.

Program łączy mapy lokalne z informacjami o spotach i okazach,
ułatwiając zapisywanie własnych miejscówek podczas gry.

---

## ✨ Najważniejsze funkcje

### 🗺️ Mapy lokalne

- interaktywne mapy łowisk RF4
- dokładne współrzędne
- dodawanie własnych spotów
- numerowanie spotów
- zaznaczanie spotu lewym przyciskiem myszy
- grupowanie spotów znajdujących się blisko siebie
- edycja i usuwanie zapisanych miejsc
- ulubione mapy

### 🌐 Mapy społeczności NNF

- dane społeczności **NoNameFish**
- spoty z okazami
- informacje o złowionych rybach
- zdjęcia okazów
- grupowanie punktów znajdujących się blisko siebie
- szybkie przechodzenie pomiędzy łowiskami

### 📏 Narzędzia mapy

- miarka odległości
- przesuwanie mapy za pomocą LPM
- zoom mapy
- siatka współrzędnych
- rysowanie po mapie
- strzałki
- cofanie rysunku
- własne notatki

### 💾 Zapisywanie

Możesz zachować przygotowaną mapę wraz z:

- spotami
- notatkami
- rysunkami
- strzałkami

Dane użytkownika są przechowywane lokalnie.
